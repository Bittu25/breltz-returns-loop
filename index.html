Today more than half of returns say "Didn't like the product". The reason lives in a different system (Freshdesk or a call note), not on the return.

Root cause: Breltz is not selling a bad bag. It is selling a bag that is different from the one customers were shown. The ads, the creator videos and the Myntra listing all promise more space, a bigger laptop fit and warmer colours than the Commuter 28L has. Free returns since Diwali make it costless to act on that gap. Meta never hears about the return, so it keeps scaling the ads that over-promise most.

Smart return flow: catch the misunderstanding before the pickup

This replaces the dropdown on the Shopify returns app. Pooja gets a real reason on every return, tied to the order ID, and some returns are saved. Try it on the phone.

Each answer is stored with the order ID, SKU, colour, channel, ad ID and creator code. That one row is what screens 1 and 2 are built from. Free returns stay free; a saved return just never needs a pickup.

  • Laptop fit: show the padded compartment video first. Pooja said some customers "haven't used the right compartment".
  • Too small: offer an exchange to the Voyager 40L before a refund.
  • Colour: offer a free colour swap, recorded against the ad that showed the colour.
  • Bought two colours: tag it as bracketing, so it does not count against the ad.

Closing the loop so the fix lasts

The dashboard alone tells Breltz what is wrong. These steps make the ad system learn from returns every week, without cutting spend.

Meta ad (ad ID in utm_content)→Shopify order (UTM, creator code, survey)→Return with structured reason→QC grade (weekly sheet)→Refund event back to Meta
Week 1: stop the leak
  • Change "16-inch" to "15.6-inch"
  • Fix the Myntra listing
  • Add end cards to the Riya and Ananya ads
  • Size image and fit checker on the website
Weeks 2 to 4: see it
  • Add utm_content={{ad.id}} to every Meta link
  • Join Shopify, the returns sheet and Freshdesk on order ID
  • Launch the smart return flow
  • Weekly creative P&L in the Monday meeting
Month 2 onwards: teach Meta
  • Send refund events through CAPI so Meta learns net value
  • Scale and kill on ROAS after returns, not reported ROAS
  • Promise check before every new creative goes live
